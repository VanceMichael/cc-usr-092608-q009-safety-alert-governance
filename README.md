# 安全预警证据归并与闭环督办

归并多源安全预警，保留人工裁决、处置责任、误报影响和督办证据。

## 参与方与事实

主要参与方包括应急管理人员、基层处置人员、企业安全人员、分析研判人员、规则维护人员、保险服务人员。领域资料记录以下已经确认的事实：

- 浙江上线电动自行车充停、电焊作业、城乡积涝和安责险等安全治理应用
- 相关应用利用视频分析、多源数据融合和智能预警推动闭环处置
- 积涝防御汇聚气象、水利、建设和公安数据并完整留存处置过程
- 同一风险可能由视频、电流、定位、气象或人工举报重复触发
- 充停位置、动火资质、积水阈值与安责险服务承诺分别使用各自的核验规则
- 实现覆盖接入留存、关联建议、人工三态裁决、责任链、移送脱敏、迟到重评、误报四眼关闭与版本倒查

## 业务约束

- 多源事件归并：相同来源事件重复到达不新建工单
- 模型规则版本：四类规则各有版本，误报可按算法版本倒查
- 人工确认：关联三态裁决与立案均须人工，自动结论只辅助
- 处置责任链：唯一当前责任单位，措施按序追加，并发不分叉
- 隐私最小披露：移送包按目的白名单裁剪、剥离个人信息
- 系统性误报：版本维护人不得独自关闭本版本异常，须四眼复核
- 迟到数据重评不改写历史命令；停机恢复后逾期与待复核项重现

## 仓库结构

- `contracts/context.schema.json` 领域资料结构；`contracts/snapshot.schema.json` 停机快照契约
- `fixtures/context.json` 不含真实身份信息的领域资料示例（版本 2）
- `src/safety_context.py` 读取并校验领域资料
- `src/governance/` 领域服务：
  - `model.py` 事件、建议、裁决、工单、责任链等不可变记录
  - `rules.py` 充停位置/动火资质/积水阈值/保险承诺四类核验规则
  - `disclosure.py` 跨部门移送证据白名单与脱敏
  - `store.py` 追加记录、乐观锁、快照与恢复
  - `service.py` 服务门面：接入、裁决、立案、责任链、移送、误报复核、迟到重评、版本影响
- `docs/domain-rules.md` 领域边界；`docs/service-rules.md` 规则逐条落实
- `tests/` 共 31 个用例（含原有资料校验），覆盖全部硬约束

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
