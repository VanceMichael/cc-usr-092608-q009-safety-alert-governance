# 领域边界

归并多源安全预警，保留人工裁决、处置责任、误报影响和督办证据。

现有领域资料围绕以下边界组织：

- 风险事件接入：视频、电流、定位、气象、人工举报、安责险报告六类来源，
  事件原样留存，相同来源事件重复到达不新建工单
- 证据关联裁决：系统只给关联建议与理由，分析人员裁为同一风险、
  相互独立或算法误报
- 场景规则校验：充停位置、动火资质、积水阈值、保险承诺各用各的
  规则版本，自动结论只辅助立案
- 处置督办：唯一当前责任单位与到场期限，临时控制→整改→复核→解除
  依次追加，责任链只追加、单链、并发不分叉
- 移送披露：跨部门只送对方履责所需证据，住户与从业人员信息不随单扩散
- 迟到重评：迟到气象/定位数据可调整后续措施，但不得改写历史命令
- 误报版本影响分析：误报关闭须四眼复核，停机后逾期任务与待复核误报
  重新出现，并可按算法版本倒查一批历史事件

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。

服务规则的逐条落实见 `service-rules.md`；服务实现位于 `src/governance/`，
停机快照结构见 `../contracts/snapshot.schema.json`。
