# 领域边界

归并多源安全预警，保留人工裁决、处置责任、误报影响和督办证据。

现有领域资料围绕以下边界组织：

- 风险事件接入
- 证据关联裁决
- 场景规则校验
- 处置督办
- 误报版本影响分析

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。

## 服务实现与边界对应

- 风险事件接入：`service.ingest` 原样留存事件，按来源流水号幂等去重；
- 证据关联裁决：`correlation` 只给建议与理由，同一风险/相互独立/误报由 `service.decide` 与误报双人复核承载；
- 场景规则校验：`verification` 中充停、动火、积涝、保险各持独立规则版本，结论仅辅助立案；
- 处置督办：立案锁定唯一责任单位与到场期限，临时控制、整改、复核、解除依次追加，升级与转派受责任链版本号约束；
- 误报版本影响分析：误报关闭须非维护第二人复核，`analyze_algorithm_version_impact` 可按版本回溯一批历史事件。

所有状态变化以追加事件落盘，重放日志即可完成停机恢复；转派证据经最小披露组装，身份信息不随工单扩散。
